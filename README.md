## О проекте

**libre-oge** — это LaTeX-класс для создания контрольно-измерительных материалов (КИМ) в формате российских экзаменов. Этот класс нацелен на включение в себя всех форматов ГИА, таких как ОГЭ, ЕГЭ, ГВЭ и ВПР.

Изначально этот проект был создан для того чтобы любой человек без навыков в программировании или профессиональной верстке смог бы воссоздать ОГЭ по любому предмету. На сегодняшний день уже сделаны шаблоны для ОГЭ и ВПР, которые позволят любым людям или организациям создавать реалистичные бланки КИМ. 

## Особенности

Ключевым в этом движке было создать код который бы работал во всех трех самых популярных движках LaTeX: LuaLaTeX, XeLaTeX и pdfLaTeX.

Класс основан на классе exam, адаптированного под ГИА. Процесс разработки соединения к оригинальной системе баллов в пакете exam продолжается до сих пор.

По умолчанию в классе стоит шрифтовая семья Libertinus, близкая по духу к Times New Roman который использовался в оригинальных бланках, но полностью бесплатная и свободная.  В будущем будет добавлена возможность выбрать любой шрифт, сейчас это можно сделать только через явное переопределение. 

Основная единица класса - окружение `task`. С его помощью вы можете создавать задания с реалистичным указателем, отступами и ответами.  

В классе представлены различные макросы для создания полей для ввода ответов, все поля точно повторены на основе оригинальных материалов ФИПИ, таких как демо версий ОГЭ и ВПР.

Больше информации вы можете узнать из готовых шаблонов, примеров и документации.

## Установка

1. Скачивание

Нужно скачать репозиторий в любую папку на вашем пк. Делается это либо через кнопку `Загрузить исходный код`, либо если вы знакомы с git через эту команду:
```bash
git clone https://github.com/CSharpKun/libre-oge.git
```

2. Установка

Вся установка заключается в том чтобы положить файлы libre-oge.cls  и/или region-patterns.sty и шаблоны в папку вашего проекта.

3. Зависимости

Самый сложный этап установки это установка всех зависимостей. К счастью большая часть зависимостей уже встроена. 

### Для пользователей TeXLive 2026
Вам нужно установить все пакеты вручную. 

---

Для LuaLaTeX:
```bash 
tlmgr install exam geometry pgf tikz xcolor fontsize fontspec libertinus-fonts unicode-math polyglossia luacode
```

Для XeTeX:
```bash
tlmgr install exam geometry pgf tikz xcolor fontsize fontspec libertinus-fonts unicode-math polyglossia
```

---

Для pdfLaTeX:
```bash
tlmgr install exam geometry pgf tikz xcolor fontsize libertinus-type1 fontenc inputenc babel
```

### Для пользователей MiKTeX или MacTeX
Все должно установится автоматически. 

## Примеры и шаблоны

В корневой папке находятся два шаблона: oge-template.tex и vpr-template.tex. 

Они содержат базовые тексты для ОГЭ и ВПР, а также демонстрируют различные поля для ввода ответов и конструкции, адаптированные из класса exam.

Более подробные и реалистичные примеры вы можете найти в папке examples. Там находятся шаблоны и варианты различных ОГЭ, в основном не существующих в реальности. Они созданы чтобы продемонстрировать на что способны наши шаблоны и LaTeX.  

## Лицензия

Сам класс libre-oge.cls, а также вспомогательный класс region-patterns.sty лицензированы под лицензией LPPLv1.3c. Это значит, что при изменении любого из этих двух компонентов вы обязаны переименовать их и оставить ссылку на оригинальный проект. В шапке файла должен остаться оригинальный копирайт с добавлением вашего. Правила распространяются только на тех, кто изменяет сам класс, а не создаёт свои работы в формате .tex с его помощью.

Шаблоны, документация и все остальные материалы лицензированы под лицензией CC-BY-SA. Это значит, что вы можете свободно использовать их для создания .tex и .pdf файлов вариантов КИМ, но вы обязаны сохранить авторские ремарки, шапку файла и лицензировать свой изменённый файл под CC-BY-SA. На это правило распространяются и произведённые работой движка .pdf или иные файлы, которые относятся к готовой работе.

Примечание касательно копирайта: вы обязаны указать копирайт даже в том случае, если вы распространяете не оригинальный .tex файл, а скомпилированный .pdf файл. Рекомендуется указывать авторство в нижнем колонтитуле файла через сконфигурированные переменные `\date` и `\author`.

Если данный способ вам не подходит, я разрешаю вставить копирайт на сайт организации/частного лица, в особенности при скачивании материалов, созданных или являющихся производными от оригинальных .tex файлов, или ознакомиться с копирайтом при личной выдаче материалов третьим лицам. Если вы выпускаете сборник на основе представленных шаблонов, то вы можете указать авторство на первой и/или последней странице сборника.
